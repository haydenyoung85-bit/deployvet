DeployVet checks apps built with AI and no-code tools for common security holes and bugs. It gives you a report and steps to fix what it finds. DeployVet is not a penetration test. A clean report means we didn't find the issues we check for. It does not mean your app is safe.

3. How the checks work

  • The Free Check looks only at your public site, like a visitor would.
  • The paid scan can also read a public GitHub repo or Supabase project you give us. We only read. We never change your app, code or data.

  • Never give us a secret key, password or service_role key. We only need public info.
