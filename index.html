Find the boring problems on your client sites before someone else does.

DeployVet checks your client sites for the boring stuff that gets people hacked or embarrassed: leaked keys, open databases, missing HTTPS, broken pages. The first check is free. $29 a month watches up to 5 sites.

No signup or card. Please only check sites you own or look after for a client. It is not a penetration test. So far it has checked more than 600 sites, and our first paying customer signed up this October.

What it checks

  • API keys and secrets left in the page code
  • Supabase or Firebase databases that anyone can read
  • HTTPS, redirects and certificate problems
  • Missing security headers and exposed files such as .env or .git
  • Broken links, missing pages and source maps that show your code

Questions

Is this a penetration test?

No. DeployVet only looks at what anyone on the internet can already see. It finds common, real mistakes, but a clean result is not a guarantee that a site is safe.

Can I check a site I don't own?

Only if you look after it, for example for a client. Please don't check other people's sites.

Will you charge me later?

The free check never charges you. A scan is a one-time $7. Pro is $29 a month and you can cancel any time. Canceling stops the next renewal.
