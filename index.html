What we check

Common problems anyone can see from the outside

We look at your live site the way an outsider would. Nothing is changed and nothing is logged in to.

  • Exposed keys and secrets

    Searches your public JavaScript for keys that belong on a server, such as payment, AI and database service keys.

  • Open databases

    Tests whether a public database key lets strangers read or write data that should be private.

  • Exposed files and routes

    Looks for environment files, git folders, backups and admin or API routes with no login.

  • Security headers

    Checks CSP, HSTS, framing protection and other headers that block common attacks.

  • HTTPS

    Flags a missing HTTPS redirect, and files loaded over plain http.

  • Broken pages and basic SEO

    Finds broken pages and links, and basic search-visibility misses.

FAQ

Common questions

Need something else? Email support@deployvet.com.

What is DeployVet?

DeployVet runs an outside-in security and bug check on public websites and web apps. It was made by Hayden Young and was previously called Launch Guard.

Is this a penetration test or an audit?

No. DeployVet finds common, known issues from the outside. It is not a penetration test, an audit or a certification. If your site holds very private data or takes payments, get a professional security review as well.

Do you need my code or database?

Not for the free check, which only looks at your public site. The paid Scan can also use read-only access to a repository or database project you choose to share. We can read but not change anything.

Which sites can you check?

Any public website or web app, whether it was hand-coded or built with an AI or no-code tool. Sites that use Supabase get extra database checks.

Can I check a site I do not own?

Only if you manage it for the owner. For paid scans and public score listings, you must prove control of the site with a DNS record or a meta tag.

Will you charge me later?

No. You pay once, up front, for a Scan ($7) or the Fix it pack ($10). Neither is a subscription and nothing renews.

Does a clean report mean my site is safe?

No tool can promise that. A clean report means we did not find the issues we check for.

Does DeployVet fix my site?

No. We never change your site. We tell you what is wrong and give you steps and prompts to fix it.
