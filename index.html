01 · What we check

What a stranger could find on your site.

The Free Check looks at your live site from the outside, like a stranger would. Here is what it looks for, with examples.

  1. Leaked keys

    We scan your JS files for secret keys that should never reach the browser.

    // assets/index-4f2a.js (example)
const stripe = Stripe("sk_live_••••••••••3kQ");
↑ A secret key. It belongs on the server.

  2. Open Supabase data

    We find your public Supabase key and test if Row Level Security keeps tables closed.

    -- what we test, with your public key
select email from profiles limit 1;
→ 1 row returned. RLS is off.
fix: alter table profiles enable row level security;

  3. Open admin and API routes

    We look for admin pages and API paths that work with no login.

    # no cookie, no token
GET /admin        200 OK
GET /api/users    200 OK

  4. Security headers

    We check the headers that guard your site from common web attacks.

  5. Mixed content

    We flag files that load over plain http on a secure page.

  6. Broken pages

    We find pages and links that fail before your users hit them.

05 · FAQ

Good questions.

Still stuck? Email support@deployvet.com.

What is DeployVet?

DeployVet checks apps built with AI and no-code tools for security holes and bugs. It was made by Hayden Young. It used to be called Launch Guard.

Which tools do you support?

Lovable, Bolt, Replit, Cursor, v0 and Bubble. Apps that use Supabase work too.

Is this a penetration test?

No. DeployVet is not a penetration test. It finds common, known issues. If your app holds very private data or payments, get a pro security review too.

Do you need my code or database?

Not for the Free Check. It only looks at your public site. The paid DeployVet Scan asks for read-only access to your repo or Supabase project. We can read but not change anything.

Can I check an app I don't own?

No. You must prove you own the site with a DNS TXT record or a meta tag first.

Will you charge me later?

No surprise charges. You pay for a DeployVet Scan before it runs. Pro is billed up front each month or year, and you can cancel any time.

Does a clean report mean my app is safe?

No tool can promise that. A clean report means we did not find the issues we check for. Think of it as a health check.

Does DeployVet fix my app?

No. We never change your app. We tell you what is wrong and give you steps and prompts to fix it.

How do I get help?

Email support@deployvet.com.
